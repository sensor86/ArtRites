# Last Rites (1997) — Reverse Engineering & Automap

Extracted 3D level geometry (with textures) from the proprietary CLF/LIF binary
formats used by *Last Rites* (Ocean Technology Group / Rage Software, 1997), and
a real-time automap overlay that reads the player's live position out of DOSBox
memory while you play.

Made out of love for a genuinely underrated, forgotten game — not for profit,
and not to redistribute the game itself. **This repo contains no copyrighted
game assets** — no original level files, no textures ripped from the game, no
executable belonging to Ocean/Mindscape/whoever holds the IP today. Everything
here is either original tooling (Python + a compiled Windows build of it) or
data *derived* by that tooling from a legally-owned copy of the game, meant to
be regenerated by anyone who owns the game themselves.

## AI disclosure

This project was reverse-engineered with heavy use of AI assistance (Claude,
via Claude Code) as a pair-programming / disassembly-reading tool throughout
the process — reading decompiled output, proposing hypotheses about struct
layouts, iterating on extraction scripts, and drafting documentation. All
findings were verified against byte-level evidence from the game's own files
and a Hex-Rays decompilation before being treated as fact (see the
CONFIRMED/INFERRED labeling convention throughout `docs/`). If you're
suspicious of AI-assisted RE work, the raw session notes in `docs/` show the
back-and-forth and you're welcome to check any of it yourself.

## What's here

- **`tool/`** — the real-time automap: `automap.py` (source) and
  `LastRitesAutomap.exe` (standalone Windows build, no Python needed). Reads
  DOSBox's emulated memory to track your zone/position live; does not modify
  any game file. See `tool/README.txt` for install/controls.
- **`exporters/`** — the canonical Python scripts used to pull geometry and
  textures out of `.CLF`/`.LIF` files you already own, and to decode the
  switch/door/trigger logic embedded in each level.
- **`exports/`** — pre-generated output from those scripts, so you can look at
  the levels in Blender without running anything yourself:
  - `textured/` — full textured OBJ+MTL+PNG for the 5 playable city/mall/sewer
    levels (MISS01, 04, 06, 07, 08)
  - `world/` — untextured world-space OBJ for every level, including the boss
    arena and multiplayer maps
  - `geo_json/`, `logic_json/` — structured per-level data (geometry / decoded
    switch-door-trigger wiring)
- **`docs/`** — file format reference, the switch/door/trigger logic reference,
  and the latest running research notes.

## Using the exporters yourself

You need your own legally obtained copy of the game (GOG or Steam) and the
`.CLF`/`.LIF` files from its install directory.

```bash
pip install pillow

# Textured export (5 playable levels)
python exporters/export_textured_v24.py MISS01.CLF MISS01.LIF

# Geometry-only export (any level, no LIF needed)
python exporters/export_obj_transformed.py MISS01.CLF

# Blender import: Up=Y, scale=0.01
```

## Using the automap

See `tool/README.txt`. Short version: drop the `tool` folder into your Last
Rites install directory (next to `dosbox.exe`) and run
`Play Last Rites with Automap.bat`.
